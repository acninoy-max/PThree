# Testlauf für Joël — einmal komplett, live

Ziel: Der ganze Weg einmal am Stück auf https://pthree-wine.vercel.app,
bevor die 3–5 Testtrainer eingeladen werden.

1. Mail „You're invited to PTHREE" kommt an → „Set your password" →
   Passwort setzen → landet im Trainerbereich (Feed).
2. *Clients → Add client* mit einer **zweiten** E-Mail-Adresse, die du
   auf dem Handy abrufen kannst → danach öffnet sich direkt der
   Plan-Dialog.
3. Plan anlegen **oder** unter *Training → Programs* eine Vorlage
   zuweisen.
4. Beim Klienten unter *Details* „Create invitation link" → Link aufs
   Handy schicken → dort Konto anlegen.
5. Auf dem Handy ein Training loggen (Ziffernblock, Pause, Abschließen).
6. Auf dem Handy ein Check-in schicken.
7. Am Rechner beim Klienten nachsehen: Einheit unter *Track*, Check-in
   unter *Check-ins*?
8. Auf beiden Seiten unter *Profile* ein Feedback schicken.
